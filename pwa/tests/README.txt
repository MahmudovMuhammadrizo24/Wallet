SINOVLAR (ixtiyoriy, faqat dasturchi uchun)
Ilovaning ishlashi uchun bu papka kerak emas. Uni o'chirib tashlasangiz ham bo'ladi.
Ishga tushirish:  npm i playwright && npx playwright install chromium && node tests/run-all.js
Sinovlar tarmoqqa chiqmaydi: tashqi so'rovlar soxta javoblar bilan almashtiriladi.
Ular tekshiradi: PIN, Kontaktlar, USDC/DAI yuborish, xavf ogohlantirishlari, zaxira nusxa, Mining,
buzilgan API javoblariga chidamlilik (HTML in'ektsiya), tezlik, BTC zaxira server, 8 xonali PIN, parol va Face ID (virtual autentifikator bilan).
Natijalar WORK muhit o'zgaruvchisidagi papkaga yoziladi (standart: tizim vaqtinchalik papkasi).
